# Implement a design from scratch

![Webpage preview](https://intranet-projects-files.s3.amazonaws.com/holbertonschool-webstack/622/Archive.zip)

This project is about implementing a web page from scratch based on a designer file made by Nicolas Philippot. The page is built using only HTML and CSS, without any external framework or JavaScript. The goal is to match the design as closely as possible while following good practices in accessibility and responsive design, including a mobile version for screens 480px wide or less.
